Test whether the strongest late-stage research-positive family can increase trade count without destroying stress-adjusted expectancy.

This is **not** a parameter optimization of the single best Cycle29 row. It is a finite semantic-family test.

## Gates

At minimum preserve Cycle29 strict forward gates:
- BASE PF >= 2.0
- STRESS PF >= 1.5
- BASE expectancy >= 0.30R
- STRESS expectancy >= 0.10R
- bootstrap P10 BASE mean R > 0
- BASE N >= 30
- BASE days >= 15
- STRESS N >= 20
- STRESS/BASE trade ratio >= 0.50
- all Mar/Apr/May1-15 BASE blocks positive
- all corresponding STRESS blocks positive
- largest winner share <= 0.25

Add cluster robustness:
- at least 2 semantic anchor/event variants must independently remain positive under STRESS;
- at least 2 one-axis execution neighbors must have positive STRESS expectancy;
- no single candidate may account for the entire family conclusion.

## Decision rule

PASS:
A pooled semantic family reaches sample gates and keeps strict stress/bootstrap/time-block robustness.

NEAR-MISS:
Economics remain strong but N or one robustness axis misses.

FAIL:
Pooling raises N by diluting edge, stress PF collapses, bootstrap becomes non-positive, or performance is concentrated in one block.
